## 官方依据与实际调用

PIPESIM 2022.1 `<PTK>/Examples/create_well_from_template.py` 和 `<PTK>/Help/sixgill.html`：`Model.new` → `model.copy("Simple vertical", well_name, True)` → `find` → `save` → `close` → `Model.open` → `find` → `validate` → `close`。

新增 `tools/pipesim_template_preflight.py`。输出必须为绝对 `.pips` 新路径，父目录已存在；拒绝覆盖、符号链接输出和不安全井名。模板仅固定官方 `Simple vertical`；不接受任意 Python/参数脚本。输出包括实际 Well/Completion/Tubing 上下文和原生诊断，`calculationVerified` 固定为 false。

本机官方 PTK 的 `Model.new` 要求磁盘上的内置 `.pips` 资源，直接 zipimport 会出现 `New workspace template.pips` 不存在。工具将已安装官方 `PythonToolkitModules.zip` 解到独立临时运行目录，拒绝路径越界和符号链接条目，关闭所有 Model 后清理临时 SDK 目录；不改厂商安装文件。此工具不是用户上传 ZIP 的生产解包器。

## 实跑证据

使用本机官方 SDK 连续两次创建隔离 `ConsoleWell.pips`，保存、关闭、重开成功。重开后的实际对象：

- Well：`ConsoleWell`。
- Completion：`ConsoleWell:Completion`。
- Tubing：`ConsoleWell:Tubing`。
- 官方 `model.validate()`：路径 `Well: ConsoleWell\Completions\Completion\Associated fluid`，属性 `AssociatedFluidNull`，消息 `No associated fluid`。

因此目前**没有可计算新井模型**。不提供这个生成文件作为可计算验收模型；不能以文件存在、对象存在或可重开代替真实 Profile 求解。工具 3 项测试覆盖保存关闭重开、不宣称计算、非法输入前拒绝及 copy 失败关闭；tools 全集 6/6 通过。

运行环境为支持 `Path.is_relative_to` 的 Python（3.9+），并配置官方 SDK/引擎/许可证。命令：

```text
python tools/pipesim_template_preflight.py --ptk "<PTK>/Modules/PythonToolkitModules.zip" --output "<ABSOLUTE_NEW_DIRECTORY>/ConsoleWell.pips" --well ConsoleWell
```

该命令会创建新工程，目录由开发人员明确指定；失败产物保留供诊断，不覆盖、不自动删除用户工程。官方 SDK 对 Python 的实际兼容性仍以安装版本为准。
