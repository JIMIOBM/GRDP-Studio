# L42-B：显式流体/边界的模板新井原生求解与平台再导入

日期：2026-10-06。这是开发 CLI + 当前本地业务 API 的阶段证据，不是网页建井功能交付或所有模型通用建模器。

后续已实现 [L42-C 受控模板建井 Worker 服务](L42-C.md)：共享引擎互斥、创建ID幂等、持久记录、受控下载和重启恢复已验证；下一步才是 Spring 项目注册和网页入口。

## 已实现

`tools/pipesim_template_profile.py` 按单一合同 `pipesim-template-profile-inputs/1` 接收完整 JSON。只支持明确的 `PIPESIM_FIELD`：油 API、气/水比重、GOR（scf/STB）、含水率（%）、地层压力（psia）、地层温度（degF）、出口压力（psia）、液量（STB/day）和 Study。拒绝缺项、未知字段、错误单位系统、布尔数值、非有限值及工具支持范围外数值；这些范围是本切片的保守限制，不声称等于官方全范围。

操作分层：输入验证 → 固定官方 `Simple vertical` 模板 → 新建 BlackOilFluid 并显式关联 Well/Completion → 设置地层值与 Profile conditions → save/close/reopen → 单位、关联、数值和条件回读 → 原生 model/task validate → 原生 Profile → 有限非空结果。任何回读不一致或官方诊断都不能变成成功。所有打开的模型在 finally 关闭。

模板几何、IPR 和 SDK 默认相关式仍是继承/默认来源，不宣称由用户完整输入或已校准物性。该任务为**给定液量和出口压力计算入口压力的 PT Profile**，不是求解产能/可采液量，也不是油藏—井筒双向耦合。结果单位未取到权威元数据时保留 unspecified，不据 FIELD 输入推断每个输出单位。

复用预检工具中的 SDK 物理资源临时运行目录，新增路径穿越拒绝及运行目录/import path 清理测试。生产上传 ZIP 的完整限额/鉴权与本工具无关。

## 复现与人工验收

```text
python tools/pipesim_template_profile.py --ptk "<PTK>/Modules/PythonToolkitModules.zip" --output "<NEW_ABSOLUTE_DIRECTORY>/ConsoleWell.pips" --inputs tools/examples/template-profile-field.json
```

`<PTK>` 为 Developer Tools/Python Toolkit。必须创建新父目录；已有 `.pips` 拒绝覆盖。需要与官方 SDK 兼容的 Python、引擎及许可证。退出码 0 才表示原生完整成功；诊断阻断返回 2；异常失败不能标成成功。成功并不证明平台已计算，JSON 的 `platformVerified` 始终为 false；#209 的独立平台证据单列如上。

生成文件可作为平台导入验收输入，选择 `Study 1`、PT Profile，确认14点附近的实际结果、诊断、运行记录。GUI 新建井表单还未实现；真实浏览器仍需登录验收。
