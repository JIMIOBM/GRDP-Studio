# CC01-A：运行提示收口与任务能力筛选

日期：2026-10-08。依据：[2026-10-08 耦合控制台任务书](../coupled-console-roadmap-2026-10-08.md)的 CC01 首轮切片。

## 已落地

- 软件集成 API 使用一个专用客户端。传输失败和 HTTP 200 的业务失败统一返回给调用页面，不再由公共客户端重复弹窗；201/202 受理包、二进制下载及 206 分段保留。没有改变解析融合公共请求行为。
- 主运行页面将操作结果、轮询不可确认、合同拒绝、失败、过期和部分成功按优先级合为一条运行反馈；成功操作提示不能覆盖无效/部分成功计算。保留终态状态标签和真实结果。
- 反馈绑定项目、版本、Study、任务及操作代次。切换后返回同一版本也不能恢复旧请求的报错；卸载和后续操作使旧反馈失效。
- 主运行选项同时受模型适用性与当前 Worker 声明的任务约束。空能力清单禁用新任务，不影响历史结果入口；未知任务不自动开放。历史调用者未提供清单时保持原有兼容，页面在能力检测期间明确传空清单。
- ECLIPSE Problems/Warnings/Errors 数量和部分成功提示继续可见；原文、分类及解释默认折叠，可展开查看。普通运行错误详情默认折叠；新版官方预检存在逐字段诊断时仍展开。
- 本地新版逐井对象清单默认折叠，目标井选择保留在外面；不删除模型对象、不默认取第一口井或第一台 ESP。

这不是新建一套 Run、IAM 或耦合引擎。本轮没有修改 DATA、PTK 调用参数、计算方向、单位转换、Worker/Spring 状态机及输出合同，也没有把 34 Problems 隐藏或改成完整成功。

## 代码逻辑与可读性复核

- 抽出无 UI 副作用的客户端、纯任务筛选函数、纯反馈优先级函数和小型代次反馈组合函数，避免在巨大页面内再增加多层错误拦截。
- UI 先做条件预检，后开始有效操作反馈；显式切换任务/回填方案后捕获反馈代次，防止自身状态切换吞掉提示。
- 旧错误合同没有 diagnostics 数组时也能渲染折叠摘要；保留未通过合同的数据隐藏规则。
- 登录失效处理保留；同次会话并发 401 不重复跳转，新登录会话还能再次失效。本轮不扩展登录功能。
- 结果安全提示优先于成功操作；断网/轮询失败不能触发新的 POST。原有取消、受理互斥、历史恢复测试继续执行。
- 样式仅限软件集成组件，折叠块缩进复核；不格式化整仓、不修改解析融合界面。

## 官方模型与人工验收

路径相对于各软件安装目录；下列文件在本轮已确认本机存在。交接环境使用实际安装根目录，不硬编码个人用户目录。

| 上传数据 | 操作 | 本轮验收点 |
|---|---|---|
| `<PIPESIM_HOME>/Case Studies/Well Models/CSW_101_Basic Oil Well.pips` | 上传到井筒模型；选已验证 Study，运行 PT 剖面，再“重新验证并读取” | 可用任务与 Worker 一致；原参数与有效曲线保留；提交/验证反馈为内联一条，不叠加弹窗 |
| `<PIPESIM_HOME>/Case Studies/Network Models/CSN_301_Small Network.pips` | 上传到管网模型；选已验证 Study，先运行原始管网 | 应有真实管网结果；该原件既有验收为 20 节点、16 连接；未声明的任务不显示，已有运行可恢复 |
| `<ECLIPSE_HOME>/eclipse/data/BRILLIG.DATA` | 上传到 ECLIPSE；运行后打开结果的“求解诊断”，再展开原文 | 部分/完整状态与 ECLEND 一致；计数保持可见、长原文默认折叠；Summary/二维/三维等既有入口不受影响 |

如某 DATA 引用 INCLUDE/外部依赖，应按原相对路径上传完整 ZIP 并明确入口；不要只上传孤立的被引用文件。BRILLIG 不是新双向耦合算例；原有成功不保证其他有 Problems 的工程合格。

人工反例：

1. 在允许改压力的 P101 页面启用方案，清空压力，点击一次运行：最多一个错误摘要，不创建任务；修正后方可提交。
2. 浏览器调试工具切断网络，点击一次重新验证：一个失败提示，不应同时出现全局和页面消息；恢复网络后再试。不要重复点击来制造多次操作。
3. 重新验证请求未返回时切换到 N301：旧 P101 错误不能显示到 N301；再返回 P101 也不能重新弹旧错误。
4. 运行中断网后，平台只能提示“状态暂时无法刷新”；手动刷新恢复读取，网络恢复不自动重发新任务。
5. 对已有部分成功 ECLIPSE 运行检查 Problems 计数与原始诊断；折叠原文不改变状态和计数。BRILLIG 没有 Problems 时不要人为制造此结论，使用真实已有部分成功记录。
6. 在测试环境提供仅支持 network 的能力：只显示管网模拟，历史记录仍可读。正式环境不要为了演示去篡改 Worker 的真实能力。
