# L42-C：受控模板建井 Worker 服务

日期：2026-10-06。范围：Worker loopback 内部接口、共享引擎互斥、持久创建记录和工程下载。尚未接入 Spring 项目鉴权/模型版本注册及网页建井入口，不宣称整个 L42 产品功能完成。

## 接口和边界

- `POST /api/model-creations/pipesim-template`：`requestId`（非空 GUID）、`well`（安全标识符）、`inputs`（L42-B 完整 FIELD 合同）。请求中不能指定磁盘输出路径或脚本。当前是同步创建/求解，201 表示完整成功；调用方必须设置与 Worker 求解上限相符的 HTTP 超时。断开连接可触发取消，不是后台异步队列。
- `GET /api/model-creations/{id}`：读取持久记录；创建记录和已有模型 Run ID 分开。
- `GET /api/model-creations/{id}/model`：只有完整成功记录可下载；同一个只读文件句柄核对大小/SHA 后发送，篡改返回409，失败/中断文件不授权下载。

输入验证、创建存储、适配器执行、结果合同、路由拆为独立文件，不把建模业务嵌入 Program.cs。复用 `PtkExecutionCoordinator` 的进程内和机器级互斥、`PtkProcessRunner` 的 Windows Job/start gate、超时/取消/进程树退出确认。未确认退出保留引擎锁，不能继续启动其他求解器进程。

输出只在配置 StorageRoot 下 `model-creations/<GUID>/created.pips`，拒绝目录/文件 reparse points。claim 独占创建，record 临时写入、Flush 和原子替换；相同 ID/相同参数返回原记录不再求解，字段顺序变化不改变指纹；相同 ID/不同参数409。创建失败、取消、超时保留诊断记录，且没有可下载 Model 描述。重启后已有成功记录可读；旧 generation 的 PREPARING 标记 INTERRUPTED，不自动恢复或重复建井。隔离失败产物保留供诊断，尚未实现配额/保留期清理。
