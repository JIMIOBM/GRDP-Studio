# L42-D2-F：官方 EGRID 角点修复及真实三维组件验收

日期：2026-10-07。承接 [来源校验与实算](L42-D2-E.md)。范围为软件集成 ECLIPSE 三维几何，不修改解析融合。

## 官方依据与问题

依据安装版 `manuals/FileFormatsReferenceManual.pdf`，EGRID Extensible Grid Files / Corner point grids 与 Cell Geometry（正文27、29页，PDF31、33页）：COORD定义柱线端点；ZCORN是 `(2*NX,2*NY,2*NZ)`，I维最先变化，角点按单元I/J/K及IPOS/JPOS/KPOS寻址，XY按角点Z在柱线上插值。

原界面使用 `cellIndex*8` 读取八个连续深度，只在单格模型中偶然正确；多列、多行、多层会混用其他角点。现在抽出独立可测试的角点索引函数，两处建格路径均使用官方排列；视角边界计算也按真实Z插值，不再取倾斜柱线的固定中点。

本轮只部分暂存该文件的上述修复，未带入工作区其他未提交的轨迹导入、场值写回等切片。
