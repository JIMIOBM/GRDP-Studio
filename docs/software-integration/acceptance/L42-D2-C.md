# L42-D2-C：共享建井记录与项目生命周期保护

日期：2026-10-06。承接 [L42-D2-B](L42-D2-B.md)，保持有效登录成员操作共享项目，不修改解析融合。

## 本卡范围

- 认证后的 GET `/software-integration/projects/{projectId}/template-creations` 返回该项目最近50条持久记录。仅请求ID、项目ID、井名、状态、登记版本ID；不返回输入、Profile大数组、Worker路径或原始错误。列表读取不访问Worker、不创建、不取消任务。
- 模板建井弹窗增加团队记录选择和刷新。即使新标签页没有sessionStorage请求ID，也可选择同项目的记录查询、下载成功工程或进行原有一次性登记。切换观察对象不取消前一个任务；列表状态是持久快照，选择后才查询Worker恢复状态。网络失败明确提示，不展示为“没有记录”。
- 列表和查询均有迟到响应保护；跨项目清空旧列表，进行中操作时禁止切换观察对象。当前标签页仍保留请求ID，刷新不自动重放POST。
- 软删除项目及过期回收在已有项目行锁内检查建井状态，与claim/register使用相同锁顺序。CLAIMED、PREPARING、UNCERTAIN及未知未来状态均阻止删除/回收；只有明确SUCCEEDED、FAILED、INTERRUPTED、CANCELLED、TIMED_OUT才放行。不把失联/404当取消，不删除UUID证据以允许重用。

## 人工验收（需部署新后端及兼容Worker，正常登录）

1. 在共享项目建一口模板井，记下请求ID并等待原生成功；另一个已登录标签页打开同项目的模板井弹窗，刷新团队记录并选中该井。
2. 请求ID应相同，显示已有成功Profile；选择/查询不能新增建井POST。登记后再刷新应显示同一版本ID，不产生第二次上传版本。
3. 切换另一个项目，原项目记录不能出现；未登录或会话失效时列表拒绝读取。
4. 测试项目存在正在计算或未确认任务时尝试删除，应提示先查询恢复或确认取消；真正CANCELLED后才能删除。禁止通过修改数据库制造成功/取消。
5. 断开Worker后记录列表仍可从后端读取；选中未知记录查询失败明确提示，不自动重建，不自动清理项目。
