# L42-D2-B：团队共享的模板建井业务入口与界面

日期：2026-10-06。承接 [L42-D2-A](L42-D2-A.md)。用户已明确选择“团队共享”：有效登录成员可操作共享软件项目，不迁移历史项目所有者，不以历史固定 administrator 字段做授权。

## 已实现

- 新功能的创建、查询、取消、登记、下载、能力检查均先调用原平台 Kratos whoami，要求 active=true 和非空身份 ID。浏览器 localStorage/token 不是身份依据。只转发配置的身份 Cookie，不转发无关 Cookie；跨站/未批准 Origin 拒绝；认证失联拒绝开放。响应体限64KiB、完整会话查询限10秒，不记录凭据。
- 服务端配置 `GRDP_TEMPLATE_SESSION_URL` 指向部署可访问的原平台 `/services/ory/kratos/sessions/whoami`；默认环回9919对应已有前端登录协议。容器部署必须设置其可访问地址，不能照搬宿主机环回。`GRDP_TEMPLATE_SESSION_COOKIES` 可配置部署 Cookie 名，默认支持现有两种身份 Cookie。Origin 使用已有 `grdp.cors.allowed-origins`。
- 路由前缀 `/software-integration/projects/{projectId}/template-creations`：GET `/capabilities`；POST 根创建；GET `/{id}`；POST `/{id}/cancel`、`/{id}/register`；GET `/{id}/model`。写请求要求 application/json。主前端代理按既有规则加 `/api`。
- 创建先持久化请求，再返回 HTTP202/标准code200包；单个后台调度槽，无无限队列。相同ID/项目/输入不再次调用原生创建。不同项目/输入不可借用ID；重启仅查询，不自动重放创建。
- 公开入口校验全部12个显式标量合同字段；每项目最多50条建井认领记录，项目行锁保护计数与插入。重复ID仍可恢复。不自动删除失败记录或证据。该限制是记录配额，不是完整物理磁盘配额。
- 取消请求先记录当前执行的取消意图；独立调度器在Worker可见后发送取消，处理“业务已接收但Worker尚未认领”的窗口。页面显示“已请求取消，等待进程退出”，不会把202当成CANCELLED。
- 工程登记仍复用L42-D1的哈希核验、上传事务和一次性来源绑定；下载仍经Worker长度/SHA校验。公开视图只提供状态、井名、版本ID、成功Profile点和诊断码，不暴露本机路径或原始异常。
- 软件集成工作区新增“新建 PIPESIM 模板井”。无能力合同的旧Worker禁止创建；表单初始无流体数值默认值，允许明确选用演示实验参数。创建请求ID在POST前存入本标签页sessionStorage；刷新仅查询该ID。明确的提交前400/401/403/409拒绝允许修正，响应未知不擅自换ID重建。
- 关闭弹窗不会取消计算；项目切换/卸载使旧响应失效，旧请求不覆盖新项目。原生成功展示已有PT剖面组件，可下载.pips或登记到项目；登记不等于READY/平台复算成功。

## 官方基准及验收步骤

本卡沿用安装版 Python Toolkit Help 的 Model.new、井copy、BlackOilFluid/完井关联、PTProfile set_conditions/validate/run/save/open。quickstart 的 Component Copying 明确copy仅支持井；没有扩展为任意设备/管网创建。模板为Toolkit内置 Simple vertical，不要求上传Case Studies模型。

升级业务后端和Worker并配置认证地址后，人工验收：

1. 正常登录，选择一个共享软件项目，点击“新建 PIPESIM 模板井”。未登录/失效会话必须拒绝。
2. 井名例如 ConsoleWell；点击“填入演示实验参数”会显式设置Study 1、API35、气密度0.65、水密度1.05、GOR200scf/STB、含水20%、地层4000psia/150°F、出口250psia、液量1000STB/d。这些是实验输入，不是官方原始工程数据/业务默认值。
3. 点击创建，检查状态/请求ID；刷新后ID不变，不重复建井。原生成功应有有效深度/压力/温度点，单位缺失不推测。
4. 下载.pips；“保存到项目并验证”只能登记一次。在项目目录等待对应版本READY，进入PT剖面运行；按本次原生返回的全部点逐点对比，而不是仅检查绿色标签。再导入下载的同一工程并重复计算，检查哈希与曲线。
5. 另建一口测试井立即取消，必须等真实CANCELLED才允许新任务；不得下载失败/取消工程。服务不可用、不同项目引用ID、越界含水率、配额达到上限等须明确拒绝。
