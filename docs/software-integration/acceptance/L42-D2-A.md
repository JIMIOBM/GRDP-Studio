# L42-D2-A：建井真实取消和预算协商

日期：2026-10-06。范围：内部Worker及Java工作流，不增加公开业务或网页建井入口。承接 [L42-D1](L42-D1.md)，不是整个L42-D2完成。

## 调用合同

- Worker `GET /api/model-creations/pipesim-template/capabilities` 返回版本化合同、固定Simple vertical模板、FIELD单位、取消支持、原生运行上限、进程清理预算和64MiB工程上限。不返回本机SDK路径或用户信息。
- Java创建前验证能力合同，HTTP总预算使用Worker运行上限+清理预算+30秒余量，不再假设业务端默认600秒等于Worker设置。不支持能力合同的旧Worker被拒绝，不能用模拟响应填充。
- Worker `POST /api/model-creations/{id}/cancel`：202仅表示已发取消信号；200表示返回已提交终态，原终态不变；未知ID404、空ID400、当前generation没有执行的PREPARING记录409。终态取消不可重写模型、诊断或时间戳。
- Cancel信号与成功持久化有同一同步顺序点：取消先到不能发布SUCCEEDED；成功已提交则取消返回原成功记录。请求断开和明确取消共用原生进程停止通道；未确认进程树退出仍保留引擎互斥，不把“发了信号”当作安全退出。
- Java工作流先验证创建记录属于指定项目，再调用取消；202不能落库为CANCELLED，继续GET读真实终态。已有终态不再向Worker发送取消。同一ID仍不会重复建井。
