# L42-D2-H：团队建井取消意图持久化与重启恢复

日期：2026-10-07。承接 [分段协议复核](L42-D2-G.md)。本卡只完善团队模板建井恢复，不改解析融合、角色权限或商业计算任务范围。

## 新增业务能力

此前取消意图只存在后端Active对象中，重启后丢失，团队成员回读记录看不到取消进度。现在新增独立持久取消请求表，以创建请求UUID为唯一键、首次请求时间为证据；无需改写历史请求/结果JSON或原生Worker状态。

- 在发送取消信号前，项目行锁与任务行锁下保存意图；重复或并发取消只保留一条证据。
- 只允许当前项目已认领且CLAIMED/UNCERTAIN/PREPARING的任务申请取消。错项目、未知UUID、已完成任务不能插入意图或误取消其他任务。
- 后端重启/换成员后，公开状态查询按持久意图继续发送取消并回读原生状态；不会再POST建井。重启后无用户查询时不主动扫描全部历史任务，本卡不提供后台全量恢复队列。
- 取消接口失联/404时仍尝试读取真实任务状态；404不是没执行/已退出的证明。两条链路均不可用则保持未确认并返回查询错误，不修改为REJECTED/CANCELLED、不自动删除项目。
- 原生先成功、失败或超时等真实终态照常保存；取消意图不会把成功伪装成CANCELLED。终态不再显示“等待取消”，首次意图证据保留。
- 页面提示取消意图已保存，查询可以接续；取消信号返回202不能当作进程退出。现有下载/登记/项目删除保护不放宽。

## 代码与验收

独立表在现有初始化器中幂等创建，UUID索引控制去重；没有强制解锁、手工改终态、角色扩权或删除证据入口。完整身份操作审计与管理员处置仍属后续门，首次请求时间不冒充操作者审计。

覆盖：存储对象重建后意图保留、8次并发取消去重、错项目/未知任务拒绝、成功先完成不改写、发送失败前已持久化、取消404仍查询、恢复不创建。UI使用真实组件与模拟HTTP验证刷新后提示及保护、成功抢先完成后的按钮状态，不是原生重启/真实登录验收。

测试入口改为普通Vite模块解析，不再直连不稳定的`.vite/deps`缓存URL；独立源码首次运行暴露缓存模块404，修正入口后整套复验，不将首次失败计为通过。

最终暂存索引独立源码：后端软件集成242项通过，0失败、0错误、0跳过，含真实模板来源/下载冒烟，Java21/Maven打包通过；前端模板界面契约8项通过、标量合同4项通过，生产构建通过。原生冒烟仅验证既有成功工程，不是本卡新增取消后重启的真实网页登录验收。已有Sass/大包告警未顺带修改。

## 人工验收（需部署新版后端，正常登录）

无需上传新的官方文件。使用Toolkit内置Simple vertical、L42-D2-B显式实验参数：

1. 在测试共享项目建井，记录UUID，点击取消。页面应显示已请求取消、等待真实退出；不能立即下载或解锁删除。
2. 刷新或由另一位有效登录成员从团队列表选择同UUID；仍显示已保存意图，不创建新井。
3. 经受控安排重启业务后端（不停止商业引擎、不中断其他用户任务），恢复查询应继续跟进取消；UUID和原始输入不变。若原生已先完成，就显示真实完成而不是已取消。
4. 计算服务失联时保持未确认和项目保护；恢复服务后查询真实状态。不要篡改数据库或杀正在使用的原生进程来制造验收。
