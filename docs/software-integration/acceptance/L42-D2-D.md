# L42-D2-D：执行前拒绝与失联状态区分

日期：2026-10-06。承接 [共享记录与生命周期保护](L42-D2-C.md)。本卡只修建井业务状态，不扩大商业引擎任务范围、不改解析融合。

## 业务规则

此前所有创建异常都持久化为UNCERTAIN，Worker在计算前明确忙碌/缺少Toolkit时也可能留下长期未确认记录。现在新增后端本地终态REJECTED，表示有证据证明未启动本次建井，不冒充Worker的FAILED/CANCELLED或任何计算结果。

- 能力检查失败发生于建井POST前，属于明确未发出创建请求。
- 建井POST返回的拒绝只按已安装Worker代码及HTTP状态组合认定：400 INVALID_TEMPLATE_INPUTS；503 PTK_UNAVAILABLE；409 WORKER_BUSY、PIPESIM_GLOBAL_BUSY、COORDINATOR_STOPPED。依据为Worker的TemplateCreationService.CreateAsync及PtkExecutionCoordinator：这些分支位于持久认领/原生适配器启动之前。
- CREATION_ALREADY_CLAIMED、CREATION_STORAGE_ERROR、CREATION_ID_CONFLICT、未知409/5xx、无效/丢失POST响应仍属于UNCERTAIN。已有持久Worker失败记录仍回读为其真实终态。绝不能仅凭HTTP409/503就认定“没执行”。
- REJECTED只从CLAIMED且无Worker记录转换，不覆盖已回读结果；相同ID仍不重发创建，也不能随后借用其他Worker结果。页面显示“执行前已拒绝（未启动建井）”及安全诊断码CREATION_NOT_DISPATCHED，禁止下载/登记。
- REJECTED可以人工开始新任务（使用新ID），不会自动重试或取消其他任务；仍消耗既有持久记录配额。UNCERTAIN不解锁自动重建或项目删除，GET404不作为取消证明。
- 修复前留下的历史UNCERTAIN没有拒绝证据时不猜测改成REJECTED；仍须查询恢复或后续受审计的管理员处置。
- 项目删除/回收将REJECTED识别为已确认本地终态；未确认状态保护不变。原生SDK/输入/结果合同无变化。
