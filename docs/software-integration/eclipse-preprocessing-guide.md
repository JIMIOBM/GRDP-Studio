# ECLIPSE 表格建模使用说明

在统一控制台选择一个项目，点击 **Excel / CSV 表格建模**。无需先上传 DATA，也无需已有成功计算。

## 三个教学案例

| 类型 | 原始官方算例 | 建议演示的参数修改 | 查看什么 |
| --- | --- | --- | --- |
| E100 注水开发 | SPE9 | 注采计划中 `WCONINJE.1.1.5`：5000 → 1000 STB/day | 注水、累计产油、压力变化 |
| E300 组分 | SPE3_GASCOND | 注采计划中 `GRUPSALE.1.1.2`：1500 → 1200 Mscf/day | 售气目标调整后的组分开发响应 |
| E300 热采 | THERM3 | 注采计划中 `WINJTEMP.1.1.2`：0.70 → 0.50 | 蒸汽干度调整后的产油、井温和井压 |

参数变化的效果以实际计算为准，不预设增产结论。SPE9 原例存在压力限注，5000 改为 4000 时主要累计指标可能不变；1000 的教学方案更便于观察注水减少及其响应。热采的井底压力限制是上限，不是实际蒸汽压力。

## 操作步骤

1. 选择模型类型，下载“教学 Excel”或“对应 CSV”。首次使用也可点击“载入填写示例”。
2. 在表格黄色数值列填写数据，保留参数编号和原单位。导入 `.xlsx` 或 UTF-8 CSV，确认编号、数值、单位三列对应。
3. 页面按数据表显示参数，可以直接修改。查看并确认模板来源、固定选项和适用范围，再点击“检查数据并预览”。错误会列出工作表、行和字段；修正后重新检查。
4. 检查输入三维储层与井、孔渗分布、物性曲线、组分比例及注采时间轴。这些是**输入预览，尚未求解**。
5. 点击“生成并计算”。系统创建新模型版本，通过校验后调用本机官方求解器；可以关闭页面，重新进入后查看生成记录。
6. 成功后点击“查看完整计算结果”进入曲线页；前处理工作台中的“查看三维计算结果”，或已保存工程中的“三维场值”，可查看本次原生网格、压力等场值、剖面及报告步演变。它们与输入预览分开标识。
7. 在前处理的已保存工程中点击“基于此版本继续编辑”，等待参数载入后修改上表参数、重新检查并计算，再选择原成功运行，点击“对比两次真实计算”。
8. “下载生成工程与来源”包含 DATA、原始表格、提交参数、模板版本及校验值。输入源和生成记录均保留；重复点击同一生成请求不会重复登记或计算。

## 表格约定与适用范围

- 每行是一项已定义工程参数，参数编号用于对应模板，不是任意列的自动地质解释。多工作表 Excel 与对应 CSV 可生成相同 DATA。
- 三套表格从本机 ECLIPSE 2024.1 官方算例转换，标注为“官方算例转换教学数据”；不是官方发布的 Excel，也不是现场实测。空白模板不能直接运行，缺失值不会填零或套用教学原值。
- 首版固定网格维数、井数量、井组拓扑、相态和工程模板；可编辑表中列出的网格尺寸、孔渗、初始状态、物性、井位与完井、注采目标和时间步等数值。不能通过添加未知参数或改字段编号扩展模型结构。
- 保留 FIELD 原单位，不隐式换算。`fraction` 填 0–1，`degF` 是华氏温度，`degR` 是绝对温度，日期用 `YYYY-MM-DD`。公式输入、未知或重复参数、缺失值和不合约束的输入会被阻止。
- SPE9 生成工程规范井名填充空格，并明确列出平台支持的全场、井曲线；网格场值由原生三维结果提供。三类工程均补充可视化所需输出，具体变更写入来源档案，不改变物性或注采方案。
- 方案对比只比较同一模板版本、同一起算日期、同一指标对象、同一原单位及共有真实报告时刻，不补零或插值。真实现场应用仍需专业人员使用现场数据和独立参考结果验证。
