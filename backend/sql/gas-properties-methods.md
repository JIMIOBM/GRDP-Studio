# 压缩因子与定压比热容计算说明

对应老师资料目录 `智慧管道-温度模块/智慧管道-温度模块` 下的 5、6、7、8、9、10。三个方法均求解状态方程，Cp 均包含理想气体热容和真实气体残差，未用固定 Z、固定 Cp 或另一状态方程替代。

| 方法 | Z 资料 | Cp 资料 | 混合方法 |
| --- | --- | --- | --- |
| PR | 5-压缩因子-PR方程 | 10-定压比热容-PR方程 | 按资料对 Tc、Pc 做摩尔分数加权；偏心因子也按摩尔分数加权 |
| SRK | 6-压缩因子-SRK方程 | 8-定压比热容-SRK方程 | 同上；使用资料的 0.48508、1.55171、−0.15613 温度函数系数 |
| BWRS | 7-压缩因子-BWRS方程 | 9-定压比热容-BWRS方程 | 完整 11 参数及资料中的线性、平方根、立方根混合规则；本版本明确取全部 Kij=0 |

PR/SRK 的拟临界混合方式是老师资料给定的近似混合方法，不等同于采用二元交互参数的 van der Waals 混合规则。BWRS 的 Kij=0 是未标定假设，不能将含较多酸性组分的计算结果表述为经实验标定的精确物性。

## 单位与数据来源

接口输入为压力 MPa（绝压）、温度 ℃、组分摩尔分数 0～1；内部统一为 Pa、K、mol/m³、J/(mol·K)。输出 Z 无量纲，Cp 为 J/(kg·K)，密度为 kg/m³，摩尔质量为 kg/mol。R=8.31446261815324 J/(mol·K)。组成总和容差为 1e-6，仅对容差内的舍入误差归一化，不自动补甲烷或补齐缺失组成。

算法需要完整气体组成。原 PVT 的旧格式只有 H₂S、CO₂、N₂ 三项非烃含量，不能据此推算烃类组成，也不能要求这三项人为凑满 100%。实际使用的全部烃类与非烃组分合计为 100%；未检出组分可明确填 0，缺失或未知含量不能自动当作零。完整组分应作为统一流体基础数据保存和复用，不能把一条固定温度的物性曲线当作完整组成。

支持 CH4、C2H6、C3H8、IC4、NC4、IC5、NC5、NC6、NC7、NC8、NC9、NC10、N2、CO2、H2S，共 15 个组分。NC6～NC10 分别是明确的正己烷至正癸烷纯组分；不代表相同碳数全部异构体的混合馏分，也不代表 C6+、C7+、C10+。碳数馏分或重端伪组分需要另外的表征数据和计算约定，程序不自动映射成正构烷烃。

临界温度、压力、摩尔密度、偏心因子、摩尔质量以及理想气体热容系数来自 [CoolProp 官方组分数据](https://github.com/CoolProp/CoolProp/tree/master/dev/fluids)。原 11 组分于 2026-09-07 核对；新增 NC7～NC10 于 2026-09-09 固定使用 **CoolProp v7.2.0，提交 `98b3523d5daa98454618d381d2ae53f7471d216b`**。使用对应 JSON 中的 `STATES.critical`、`EOS[0].acentric`、`molar_mass`、`alpha0` 与该 EOS 的 reducing temperature；只有气体理想项取自此库，PR/SRK/BWRS 残差仍由各自状态方程计算。

正庚烷 `alpha0` 使用 Aly–Lee 理想热容项，其原式为 `Cp0/R = 4 + 13.7266·[169.789/T/sinh(169.789/T)]² + 30.4707·[836.195/T/cosh(836.195/T)]² + 43.5561·[1760.46/T/sinh(1760.46/T)]²`。本实现利用恒等式 `(x/cosh x)² = (x/sinh x)² − (2x/sinh 2x)²`，严格改写成既有 Planck–Einstein 项：`n=[13.7266,30.4707,−30.4707,43.5561]`、`θ=[339.578,1672.39,3344.78,3520.92] K`、`logTau=3`。这里的负系数来自代数展开，不是负热容或拟合近似；理想焓使用相同展开，保留 `dh0/dT=Cp0`。原式与解析路径可核对该版本的 [FluidLibrary.h](https://github.com/CoolProp/CoolProp/blob/98b3523d5daa98454618d381d2ae53f7471d216b/src/Backends/Helmholtz/Fluids/FluidLibrary.h) 中 `IdealGasHelmholtzCP0AlyLee` 处理。正辛、壬、癸烷直接使用各自 JSON 的 Planck–Einstein 项，特征温度为 JSON 中的 `t` 乘 `EOS[0].STATES.reducing.T`。

曾核对 NASA CEA 原始热容系数；[NASA 当前 thermo.inp](https://github.com/nasa/cea/blob/main/data/thermo.inp) 将多数烃类原本任意设成 200 K 的下限纠正为 300 K。本次没有将其向常温以下外推，而采用上述流体物性数据中的理想气体项。

BWRS 通用常数 A1～A11、B1～B11 使用 Starling–Han 系数。老师资料仅注明“查表”，没有提供数表；数值已与 [pychemqt 官方 BWRS 实现文档中的通用常数表](https://pychemqt.readthedocs.io/en/latest/_modules/lib/EoS/BWRS.html) 核对。原始出处为 Han & Starling, *Thermo Data Refined for LPG, Part 14*, Hydrocarbon Processing 51(5), 1972，以及 Starling, *Fluid Thermodynamic Properties for Light Petroleum Systems*, 1973。这里没有引入其程序代码或额外低温四参数修正。BWRS 与热力学函数关系也可核对 [Nishiumi & Saito 1975 原论文](https://www.jstage.jst.go.jp/article/jcej1968/8/5/8_5_356/_pdf)，其文中区分原 11 参数 BWRS 与新增的 4 参数扩展。

## 对资料公式的必要校正

Word 内公式为 WMF 图片，已提取并逐一查看。原图中的以下写法不能直接编码，否则量纲或低压极限不成立：

1. 三份 Cp 资料将 `Cp−Cv` 分母中的密度写成一阶。采用摩尔密度 ρ 时应为 `Cp−Cv=T(P_T)²/[ρ² P_ρ]`。
2. PR 的 Cv 图中重复了 `T/b`，且对其所写对数比值使用了错误符号。本实现从 EOS 导出 `CvR=T a''(T) I`，其中 PR 的 `I=ln{[1+(1+√2)bρ]/[1+(1−√2)bρ]}/(2√2 b)`；SRK 为 `I=ln(1+bρ)/b`。
3. BWRS 的 `C0` 通用参数图片漏写临界温度的三次方。采用 `ρc C0/(R Tc³)=A3+B3ω`。
4. BWRS 的 Cv 图片中 `−2αdρ⁵/(5T)` 漏写了 T 的平方；正确为 `−2αdρ⁵/(5T²)`。
5. 资料中同时出现摩尔气体常数、摩尔密度及质量热容单位。计算统一先得到摩尔热容，再除以混合物摩尔质量，避免混用单位。

共同计算路径为：解 `P(ρ,T)=P给定` → 求 EOS 的解析 `P_T`、`P_ρ` 和 `CvR` → `Cp=Cp0−R+CvR+T(P_T)²/(ρ²P_ρ)` → 转为质量比热。残余内能独立按 `uR=∫₀ρ [P−T P_T]/r² dr` 计算，以定压焓导数检查 Cp。

## 数值范围与相态

温度资料 5—10 未规定 200～500 K（−73.15～226.85 ℃）、1 Pa～50 MPa 的统一温压范围；相关 PR/SRK Excel 开发模板中的温压范围栏为 `Null`。此前范围属于实现自行设置，2026-09-08 已撤销前后端固定上下限，PVT 已保存工况也不再因此被禁选。

计算仍要求有限数值、绝对压力 P>0、绝对温度 T>0，以及完整气体组成；求根、气相稳定性和结果有效性检查继续执行。超过原范围的工况可进入方程求解，是否获得结果由方程和数值校验决定。撤销统一输入限制不代表所有温压及组成都已经过实验精度验证。

PR/SRK 使用三次方程全部实根，排除负体积及机械不稳定根；多个稳定根时要求相态判别并拒绝直接输出。亚临界条件下的液体根也拒绝。BWRS 沿稀气相连续分支建立密度根区间，再二分到相对密度容差 1e-10，遇到不稳定分支不跳到液体根。Cp 在临界导数奇异处拒绝输出。

上述措施不能替代混合物露点、气液闪蒸或严格相稳定性检验。当前模块计算的是给定组成的气相性质，不提供凝析液、两相 Cp 或两相管流。黏度、导热系数、焦耳–汤姆孙系数也不是 Z/Cp 六份资料自动给出的额外算法。

## Standing 黏度资料实现（2026-09-10）

本次按用户指定资料接入 `standing-teacher-v1`，页面标注 **Standing（资料原式）**。实现复现的是文档原式，不将外部版本的系数或漏项修正悄悄混入。此前“尚未接入”的状态已由本次实现取代；经验式的实验精度和老师认可的适用范围仍没有数值验收样本。

### 输入与单位约定

- 页面/API 温度为 ℃。低压项先用 `T_F=1.8*T_C+32`；对比温度用 `Tr=(T_C+273.15)/Tc_K`。这解决 Word 写 ℃、Excel 写 K 的单位冲突，不把同一个温度数值同时当作 ℃ 和 K。
- 压力为绝压 MPa，`Pr=P_MPa/Pc_MPa`。μ 输出 mPa·s（与 cP 数值相同），Re、Prandtl 运算再乘 0.001 转为 Pa·s。
- `γg=M/(R/287.05)`，沿用本模块干空气摩尔质量基准。拟临界值沿用完整组分模型的 `Tc=Σyi*Tci`、`Pc=Σyi*Pci`；未额外引入资料未指定的酸气拟临界修正规则。
- yN2、yCO2、yH2S 来自完整组分模型，均为 0～1 摩尔分数。图中的 `log` 未标底，按此工程关联式采用 `log10`，作为明确的实现约定。

### 原式及系数

```text
μ1 = (1.709e-5 - 2.062e-6*γg)*T_F + 8.188e-3
ΔμN2  = yN2 *(8.48e-3*log10(γg) + 9.59e-3)
ΔμCO2 = yCO2*(9.08e-3*log10(γg) + 6.24e-3)
ΔμH2S = yH2S*(8.49e-3*log10(γg) + 3.73e-3)
μ1* = μ1 + ΔμN2 + ΔμCO2 + ΔμH2S
A = Σ(i=0..3) Σ(j=0..3) a[4*i+j]*Tr^i*Pr^j
μ = μ1* * exp(A) / Tr

a0..15 = [
 -2.46211820, 2.97054714, -2.86264054e-1, 8.50420522e-3,
  2.80860949,-3.49803305,  3.60373020e-1,-1.044324e-2,
 -7.93385684e-1,1.39643306,-1.49144925e-1,4.41015512e-3,
  8.39387178e-2,-1.86408848e-1,2.03367881e-2,-6.09579263e-4
]
```

程序用双层 Horner 求 A，并用 `exp(log(μ1*)-log(Tr)+A)` 避免中间 `exp(A)` 提前溢出。输入非有限/非正、无效组成、最终黏度非有限或非正时明确失败，不替换成固定值。Z/Cp 仍由 PR/SRK/BWRS 求解；Standing 是独立的输运关联式，不是状态方程的额外输出。

### 已知资料差异及验证限度

Word 的 μ1 里没有常用外部版本的 `−6.15e−3*log10(γg)` 项；本实现不补入。Word 的 `a3=8.50420522e−3` 与外部 Dempsey 版本的 `8.05420522e−3` 不同；本实现保留 Word 值。这一系数差异在 Pr=10 时就导致约 57% 的倍数差，在 Pr=20 时单项放大约 36.6 倍。原压力修正 Pr→0 时也不严格使 `exp(A)/Tr=1`（例如 Tr=1.5 时约 0.8551）；不再通过额外归一化改变原式。因此有限正值不等于已验证物理精度，尤其不能推断任意高压工况可靠。

外部核对线索为 Al-Nasser 与 Al-Marhoun 的作者论文 [Development of New Gas Viscosity Correlations，SPE 153239-MS（2012）](https://www.researchgate.net/publication/254536231_Development_of_New_Gas_Viscosity_Correlations)。外部资料仅标记版本差异；老师核准的修正式或实测气样对照仍待补充。
