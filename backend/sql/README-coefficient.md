# 产能系数保存与验证

产能系数沿用独立接口 /productivity-coefficients/records 和参数快照保存，不写入产能试井表，不在服务启动时自动改表。

## 部署前检查

在应用实际连接的业务数据库执行 [productivity_coefficient.sql](productivity_coefficient.sql)，再启动对应版本的前后端。脚本只在表不存在时创建，不更新已有同名表；已有表请先比较字段、唯一键和外键。不要为解决保存错误而删除原表或历史记录。

项目、气藏和井名必须唯一对应 project_well_heads 中的真实井。共享工作台默认项目 6 / 气藏 4，不因某台开发机使用 X 井而改动。开发机如使用其他气藏，应通过现有路由的 projectId、gasReservoirId 上下文传入真实 ID；不能只改井名或把气藏 1 的结果写到气藏 4。

未选 PVT 时，指数式压力法、压力平方法可使用手工参数计算和保存；拟压力法必须有当前井有效 PVT 结果。删除原 PVT 后，已保存记录仍通过其历史快照恢复。

## 本次逻辑约定

- 指数式气量点和压力点均必填，n/n′ 范围为 0.5～1，系数必须为有限正数。
- 注气拟合沿用二项式的 Pr/10 起点，以 Pr 为井底压力上限；注气 IPR 有九条非退化曲线及 Pr 级别的零流量点。
- 指数式无阻流量使用修正系数和 Pr 至 0.101325 MPa 的完整压差，不能用注气拟合曲线的终点气量替代。
- 输入点按原值显示，并提示其与同压下理论曲线的偏差；不会为了让点落在线上而改写系数或实测值。切换压力方法时须自行核对相应系数和输入点。
- 输入编辑后旧图和结果失效，重新计算后才可保存；切项目、气藏、井或历史记录后，旧请求不能覆盖新页面。
- 保存传输未舍入结果；显示极小流量使用科学计数。服务端复核指数式参数、拟合点、PVT 覆盖范围和标量计算结果。

## 验证命令

从项目根目录运行：

~~~powershell
node --test vue/src/utils/productivityCoefficient*.test.js
mvn -f backend/pom.xml '-Dtest=CoefficientStorageTests' test
npm --prefix vue run build
~~~

跨井测试中的 X-1～X-5 为隔离测试数据，不表示任意开发机或线上数据库均已具备这些井、PVT 或保存表。上线前须核对实际数据库并使用真实项目/气藏完成保存、刷新和恢复验收。
