# 库物质平衡：实测静压数据汇总

入口：库 → 具体储气库 → 库存评估 → 物质平衡法 → 物质平衡。

本次实现的是库级物质平衡的**来源核对、输入汇总及压力曲线**，不是库级 p/Z 回归和结果保存。来源储量合计仅用于检查权重，不能当作新算出的库动态储量。

## 库页查看智慧气藏来源

- 主页面参照库诊断曲线的左右布局：左侧为库信息、读取与来源查看操作，右侧为汇总输入数据/压力曲线，使用底部页签切换。井来源、日期检查、项目覆盖和规则收进“查看明细”弹窗，不再全部展开在主页面上。
- “井与数据来源”列出库内成员的实测结果、权重和排除原因；“当前项目的数据覆盖情况”说明哪些井有实测/计算静压结果，以及是否已经入库。结果数量只表示记录存在，不表示结果有效，也不会自动把其他井加入库。
- 在左侧选择来源井，或在“查看明细”的成员井行点击“查看参数、数据和图”，打开“智慧气藏实测来源”只读弹窗，查看原平台保存的气体性质、方法、温度、水气比上限、生产输入、输出结果和回归图。
- 直接复用共享项目的 `WellControlInventory/MaterialBalanceContent.vue` 参数栏、输入/输出切换、数据表、图表和样式。新增的 `readOnly` / `externalResult` 仅对库内来源展示启用，不改变单井页面原有默认模式。
- 来源组件只读：不导入、不重算，不调用单井计算接口。回归线来自原平台保存的输出点，不按系数补画；蓝点为原平台未排除点，灰点为已排除点。原始输入地层压力与输出 Pp 分开展示，不能互换。
- 缺失值不显示成零，失败结果不画回归线。切井、切库、刷新时取消旧请求并清空旧来源，数据表分页，隐藏页签恢复显示时重新适配图表尺寸。

## 已确认的业务口径

- 只取当前库成员井、当前项目及气藏范围内的“定容气藏物质平衡方程—根据实测静压”（原平台方法 ID 1）。不使用计算静压、流动物质平衡或其他项目的同名井。
- 缺少实测结果，或结果失败、动态储量不为有限正数、没有有效输入的井整口排除。产气量和产水量也不计入。
- 使用来源输出的动态储量 G 为权重，同日输入的地层压力 p 为被加权值：p̄ = Σ(Gᵢpᵢ)/ΣGᵢ。不是对回归图 Pp 值、斜率或截距加权。
- 同日累产气量、累产水量分别求和，不对累计值跨日期再次累加。
- 有多份实测结果时按更新时间、结果 ID 倒序取最近一份，显示提示；最近一份无效时不回退旧结果。
- 原平台可靠性偏低但未失败的结果保留并显示警告，不擅自设置 R² 阈值。

## 日期与单位

- 当前采用保守的共同日期策略：所有参与井同日均有有效输入才输出该日。缺失日期列出缺哪口井，不插值、不补零、不随日期改变参与井集合。
- 同日重复、缺值、非有限数值、非正压力、负气水量、已排除行不参与。累产气/水随时间下降时整井排除并说明原因。合法的零累产值保留。
- 数据库存储单位 Pa、m³；接口输出压力 MPa、气量 10⁸m³、水量 10⁴m³。日期使用业务日期字符串，不由浏览器时区转换。

## 接口与安全边界

`GET /storage-material-balance/aggregate?projectId=...&gasReservoirId=...&storageId=...`

返回成员井来源 ID、权重及排除原因、只读有效输入、同日汇总行、未对齐日期。采用只读一致性事务，验证库与项目/气藏归属以及工程未删除。超过十万来源行会明确拒绝，不静默截断。

`GET /storage-material-balance/availability?projectId=...&gasReservoirId=...&storageId=...`

返回同项目/气藏井的来源覆盖计数及当前库成员标志，不返回非成员的完整来源数据。

`GET /storage-material-balance/source?projectId=...&gasReservoirId=...&storageId=...&wellId=...&resultId=...`

只读查询指定成员井的方法 1 来源，验证全部归属字段；拒绝计算静压、非成员、跨项目/气藏来源。输入单位与汇总一致，输出截距换算为 MPa、斜率换算为 MPa/(10⁸m³)，温度 K 转 ℃、组分转百分数、水气比转 m³/10⁴m³。输出散点与回归线单独处理，不把只保存回归线的行作为生产数据。

不新建数据库表，不调用原平台 calc，不导入、删除或修改单井记录，也不修改库的选井关系。刷新或切库会清空旧结果并取消旧请求。

前端：

```sh
node --test tests/storageMaterialBalance.test.js
npm run build
```
